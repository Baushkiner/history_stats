# Дискавери: постоянный поиск новых источников

Каталог (`docs/CATALOG.md`) описывает состояние и всегда отстаёт от того, что
уже существует. Первое время это отставание никто не сокращал специально:
источник попадал в каталог, если авторы о нём знали. Так был пропущен
[k-da.dev/russia-1897](https://k-da.dev/russia-1897/ru/) — перепись 1897 года,
разобранная до уровня населённых пунктов, — его принёс пользователь, а не
процесс. Этот документ делает поиск процессом.

## Правило

**Дискавери — часть любой работы с источниками, а не отдельное занятие.**

- Задача касается слоя, темы или каталога → перед ответом делается поисковый
  проход по этой теме (запросы по-русски и по-английски).
- Полный проход по всем темам — по явной просьбе или при ревизии каталога.
- Всё проверенное записывается в журнал ниже: взятое, отклонённое (с
  причиной) и отложенное. Перед проверкой — свериться с журналом, чтобы не
  проверять по кругу.

Пригодность кандидата меряется четырьмя условиями из раздела «Каталог открыт»
(`docs/CATALOG.md`): место, время, права, проверяемость. Права из этих четырёх
ничего не отклоняют — они говорят, что из источника берётся: факты со ссылкой
берутся при любой лицензии, чужие файлы — только по разрешённой. Порядок
подключения взятого источника — там же; новый домен — строка
в `docs/HARVEST.md`.

## Шаблоны запросов по темам

Запросы — отправная точка, не список для механического повторения; при
проходе их стоит варьировать. Английский вариант обязателен: половина
датасетов по РИ опубликована западными университетами.

| Тема каталога | Примеры запросов |
|---|---|
| Переписи и учёт | «перепись 1897 база данных», «ревизские сказки датасет», "Russian empire census dataset" |
| Населённые места | «списки населённых мест оцифровка», "historical gazetteer Russia" |
| Границы и АТД | «границы губерний shapefile», "Russian empire GIS boundaries" |
| Церковь и приход | «клировые ведомости база данных», «епархия справочник оцифровка» |
| Экономика: ярмарки, заводы, дороги | «ярмарки Российской империи датасет», "Russian empire railways dataset" |
| Бедствия: голод, эпидемии, погода | «голод 1891 данные по губерниям», "drought reconstruction Russia tree rings" |
| Война и мобилизация | «потери первая мировая база данных», «Память народа выгрузка» |

## Вердикты

- **взято** — прошло четыре условия, подключается: запись в `registry.py`,
  строка в каталоге;
- **на очереди** — годится, но руки не дошли; что мешает — записано;
- **нужна договорённость** — содержимое (снимки, тексты, сканы) требует
  согласия владельца; указан контакт. Факты со ссылкой берутся и без
  договорённости — вердикт ограничивает глубину выгрузки, а не доступ;
- **ручная работа** — источник есть только сканами, нужен OCR/разбор
  (раздел 4 каталога);
- **отклонено** — с причиной: нет места, нет дат, персоналии, дубль
  уже взятого. Права причиной отклонения не бывают;
- **проверить** — найдено, вглубь не смотрели.
